# Marketing Message

## Short One-Sentence Message
StudyBridge helps university students find and book a peer tutor by subject in minutes, instead of searching chat groups during exam season.

## Message Quality Check
- Is the message clear within 5 seconds? Yes — leads with the problem (finding a tutor) and the fix (search + book in one place).
- Does it identify the target user? Yes — university students, implicitly during exam periods.
- Does it explain the problem or benefit? Yes — replaces slow chat-group searching with structured search and booking.
- Does it include one action? Yes — each channel message has exactly one CTA (Try Demo / Give Feedback / Scan QR / Test it now).
- Does it avoid exaggerated claims? Yes — no guarantees of tutor quality or speed beyond what the prototype demonstrates.
