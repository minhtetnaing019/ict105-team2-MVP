# Demo Script

## Demo Objective
Prove that a student can find a suitable peer tutor and book a session from start to finish, track the booking status, and allow an admin to manage tutors and bookings within the StudyBridge prototype.

## Demo Flow

| Step | Screen / Feature | What Presenter Says | Requirement ID | Expected User Value |
|------|-------------------|---------------------|----------------|---------------------|
| 1 | Landing Page / Homepage | Students often rely on chat groups to find tutors during exam season. StudyBridge provides a faster and more organized solution. | FR-01 | Understands the problem and target users |
| 2 | Main User Pathway | From the homepage, a student selects **Search Tutors** to begin the booking process. | FR-02 | Understands how to start using the system |
| 3 | Book a Session | Enter the student name, subject, tutor, date, and time. Leave the time field empty to demonstrate validation, then submit successfully. | FR-03, FR-10, FR-11 | Sees data validation and successful booking |
| 4 | Find Tutors | Search and filter tutors by subject to quickly locate a suitable tutor. | FR-05, FR-06 | Finds tutors efficiently |
| 5 | Tutor Profile | Display the tutor's subjects, availability, and rating before confirming the booking. | FR-07 | Helps students make informed decisions |
| 6 | Dashboard & Admin | View the booking status on the dashboard, then switch to the admin panel to approve a tutor and update a booking status. | FR-08, FR-09 | Demonstrates student and admin workflows |
| 7 | Dashboard Metrics | Present total bookings, upcoming sessions, and the sessions-by-subject chart. | FR-12 | Provides an overview of system activity |
| 8 | Closing | Summarize how StudyBridge replaces informal chat-group coordination with a centralized booking platform. | FR-16 | Reinforces the system's overall value |

## Closing Statement

StudyBridge transforms the traditional chat-group-based tutor search into a structured, searchable, bookable, and trackable platform. By simplifying tutor discovery and booking during exam season, it helps students save time while providing a better experience for both students and administrators.
